Konfigurace Core.Admin pro prostředí
Zkrácený popis produktu:
DeployInfo XML soubory slouží k definici konfigurace nasazení (deploymentu) pro jednotlivé instance aplikace 
Core.Admin. Obsahují nastavení IIS, webových aplikací, aplikačních poolů a vazeb (bindings). Soubor určuje, kam se daná 
instance deployuje a jak se má nakonfigurovat na serveru.

Vazba na prostředí:
DeployInfo je vždy specifické pro kombinaci zákazník–lokalizace–prostředí (např. tipsport-all-prod).
Každé prostředí má:
specifickou cestu k nasazení (\\{webserver}\{instance})
vlastní IIS konfiguraci
vlastní host headery a porty
Konfigurace pro prostředí
DeployInfo
Slouží k popisu IIS konfigurace a cílových cest deploymentu.
Co to je:
XML soubor popisující kořenový element <deployinfo>, cestu <deploypath> a jednotlivé weby <web>.
Cesty / umístění:
Setup/deploy/{zakaznik}/{zakaznik}-{lokalizace}-{prostředí}_deployinfo.xml
např.
Setup/deploy/Tipsport//tipsport-all-prod_deployinfo.xml
Struktura (zkrácený přehled):Dokumentace k Core.Admin

Troubleshooting
FAQ – kde hledat problémy
Když aplikace nejede:
zkontrolovat IIS bindings → odpovídají hostheaderu v DeployInfo
ověřit, že existuje target cesta \\{webserver}\{instance}
ověřit validitu XML DeployInfo (neuzavřené elementy, špatné atributy)
Když nefunguje Admin.Api:
podívat se na parametr AppName a Path="/api"
validovat, že API běží pod správným parent webem
Když nesedí databáze:
zkontrolovat atribut <deployinfo database="...">
porovnat s dokumentací instancí zákazníků v Confluence
